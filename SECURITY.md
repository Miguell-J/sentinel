# Security Policy

Sentinel v0.1 is an **experimental local development bootstrap**, not a production-ready autonomous repair controller. It has no autonomous merge or deployment endpoints.

For threat model, signature validation, identity and sandbox requirements, see [docs/security.md](docs/security.md).

Do not report credentials, access tokens, exploit payloads or undisclosed vulnerabilities in public GitHub issues. Prefer GitHub private vulnerability reporting if enabled for this repository, or contact the maintainer through a private channel.
