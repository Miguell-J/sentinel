# RFC-001 — Sentinel: domínio e fronteiras

**Status:** Draft  
**Data:** 2026-10-19

## Problema

Integrar capacidades do Cordis (orquestração), Claudear (issue-to-PR), MCP One / MCP Stack (ferramentas) e novo gateway WhatsApp de maneira desacoplada, segura e auditável.

## Decisão proposta

Um único monorepo, inicialmente com API + worker + banco, separando logicamente:

- **Control Plane:** coleta eventos, aplica políticas, cria tarefas e mantém workflow durável.
- **Agent Runtime:** executa Claude/Codex em workspaces efêmeros isolados.
- **Human Gateway:** comunica incidentes, recolhe decisões com identidade verificada.
- **Delivery Plane:** executa merges/deploys com políticas e credenciais próprias.
- **Knowledge Plane:** armazenará histórico, padrões, buscas semânticas e explicações.

## Contratos sugeridos

IncidentDetected(source, repo, fingerprint, observedAt, evidenceRef)
IncidentTriaged(incidentId, severity, confidence, triageVersion)
AgentTaskCreated(taskId, incidentId, executor, scope)
FixProposed(incidentId, repository, branch, commitSha, pullRequest)
ChecksPassed(incidentId, commitSha, checksManifest)
ApprovalRequested(approvalId, repository, prNumber, commitSha, expiresAt)
ApprovalDecided(approvalId, approverId, decision, decidedAt)
ReleaseRequested(releaseId, commitSha, environment)
ReleaseVerified(releaseId, healthEvidence)
ReleaseRolledBack(releaseId, reason)

Esses são **contratos propostos**, não eventos emitidos pelo código v0.1.

## Autonomia

- Level 0: detecção e observação.
- Level 1: investigação sem modificação.
- Level 2: criação de branch e PR; nunca merge.
- Level 3: merge com aprovação, CI e proteção do branch.
- Level 4: deploy gradual com autorização adicional e rollback configurado.

**O bootstrap implementa apenas o Level 0.** Escalar níveis requer threat model, testes e revisão.

## Principais decisões pendentes

- Motor de workflows: custom outbox + worker vs Temporal/alternativa.
- Modelo de autenticação: GitHub App e identities para WhatsApp.
- Topologia: chamar Claudear como serviço, não copiar código inicialmente.
- Contrato MCP e permissões por tarefa e repositório.
- Configuração multi-tenancy e isolamento de dados.
- Política de incidentes: prioridades, quotas, dedup TTL, retries e rate limits.
- Licença do projeto, avisos de terceiros e política de contribuições.

## Não objetivos da v0.1

Não executa agentes, não cria PRs, não envia WhatsApp, não faz merge, não faz deploy, não aplica correções automaticamente.
