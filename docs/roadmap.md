# Roadmap

## M0 — Foundation (this bootstrap)

API .NET 10, PostgreSQL, domain state graph, read-only worker, Docker Compose, secure inert Meta webhook and build checks.

## M1 — Incident-to-PR

Observability sources (Sentry / GitHub), worker queue, GitHub App, Claudear adapter, deterministic reproduction and test gates. Agents create PRs only in designated sandbox repositories.

## M2 — Human Gateway

WhatsApp Cloud API outbound templates, signed callbacks, identity linking, immutable PR head SHA, expiry/rejection/revocation and audit log. No SMS-style free-text deployment command.

## M3 — Delivery

Staging deployment, postdeploy metrics and canary, safe rollback, manual production approval, policy engine.

## M4 — Intelligence

Cordis orchestration, MCP One and MCP Stack adapters, multi-agent QA and security reviews, historical retrieval, cost and quality telemetry.
